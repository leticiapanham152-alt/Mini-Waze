# 🚗 Mini Waze Web

Um protótipo simplificado e interativo do Waze construído para navegação na web usando **JavaScript Vanilla**, **Leaflet.js** e **OpenStreetMap**.

Projetado como um mini-projeto de aprendizado para praticar manipulação de DOM, geolocalização e integração com bibliotecas de mapas abertas.

---

## ⚡ Funcionalidades

* 📍 **Geolocalização em Tempo Real**: Identifica a posição inicial do usuário no mapa via browser.
* 🗺️ **Mapa Interativo**: Renderização dinâmica de mapa aberta (OpenStreetMap).
* 🚨 **Registro de Alertas**: Clique no mapa para marcar ocorrências como radar, acidentes, trânsito ou obras.
* 📊 **Contador de Alertas**: Acompanhamento de eventos marcados na sessão atual.

---

## 🛠️ Tecnologias

* **HTML5**
* **CSS3**
* **JavaScript (ES6)**
* **Leaflet.js** (Biblioteca para mapas interativos)
